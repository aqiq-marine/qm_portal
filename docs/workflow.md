# 基本ワークフロー

1. GUIで任意のディレクトリをプロジェクトとして開く。
2. 分子の電荷・スピン・原子座標・結合を編集する。
3. 分子を参照するタスクを作成し、手法、汎関数、基底関数、溶媒、scan、freezeを設定する。
4. タスク定義から計算プログラム向け入力を生成する。
5. runを作成し、入力、標準出力、標準エラー、ログを保存する。
6. 終了状態と構造化された結果を登録する。失敗時もログと入力を残す。
7. UIでタスク、実行履歴、分子構造、結果を相互に辿れるようにする。

## 画面モデル

- プロジェクト: ファイルツリー、形式検証、設定
- 分子: 3D表示、原子・結合・電荷・スピン編集
- タスク: 計算条件、scan/freeze、入力プレビュー
- 実行: 状態、進捗、ログ、キャンセル、再実行
- 結果: エネルギー、最終構造、収束、生成アーティファクト

UIの表示状態はファイルの正本を置き換えない。保存操作を明示し、外部変更があれば再読み込みまたは差分確認を促す。
