# ADR-0003: 分子幾何編集をコマンドとトポロジーで扱う

## 決定

結合次数、結合長、結合角、二面角、連結領域移動を、分子グラフと3D座標に対する編集コマンドとして実装する。編集履歴はUndo/Redo用のスナップショットを持ち、UIイベントから直接座標を変更しない。

原子と結合には安定IDを持たせる。既存JSONのインデックス形式は読み込み時に受け入れ、IDがない場合は決定的に割り当てる。

## 理由

配列インデックスだけでは原子の追加・削除・編集履歴で参照が壊れる。結合を境界としてグラフ探索すれば、結合長・角度・二面角の対象側フラグメントを共通処理できる。

## 制約

環状構造を横切る二面角は自由回転できないため拒否する。幾何計算は倍精度で行い、現在の描画互換性のため保存座標へ戻す際のみ単精度へ変換する。

## 段階導入

幾何計算、フラグメント探索、コマンド、Undo/Redoを先にテスト可能なモジュールとして導入する。次段階でUIの選択・数値入力・プレビュー・保存を接続する。
