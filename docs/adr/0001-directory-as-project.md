# ADR-0001: 通常のディレクトリをプロジェクトの正本とする

- Status: Accepted
- Date: 2026-11-07

## Context

入力、ログ、結果は既存ファイルとして扱われることが多い。専用DBはGitでの差分確認、既存ツール連携、バックアップを難しくする。

## Decision

プロジェクトは通常のディレクトリとし、JSONベースの独自フォーマットと計算アーティファクトを保存する。アプリはこのディレクトリを読み書きするクライアントとする。

## Consequences

Git、バックアップ、手動編集と相性がよい。一方、同時編集、外部変更、スキーマ移行をアプリ側で扱う。絶対パスは保存せず、プロジェクトルートからの相対パスを使う。
