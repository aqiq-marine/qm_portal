# ADR-0002: 分子・タスク・実行を分離する

- Status: Accepted
- Date: 2026-11-07

## Context

同じ分子に複数の条件を適用し、同じタスクを条件違いで再実行する。分子と条件を一つの入力へ複製すると不整合が起きる。

## Decision

分子（molecule）、計算条件（task）、実行結果（run）を別の概念・ファイルとして管理する。taskはmoleculeを参照し、runはtaskと生成入出力を参照する。

## Consequences

再利用と履歴比較が容易になる。参照切れ、分子変更後の再計算要否、実行時点のスナップショットを扱う必要がある。runには実行時の入力とプログラムバージョンを保存する。
