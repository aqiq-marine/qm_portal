# 独自プロジェクトフォーマット（草案）

## 方針

プロジェクトはディレクトリで、トップレベルに`project.json`を置く。分子と計算設定はJSONファイルとして管理し、計算ごとの入力・出力・実行メタデータは別管理する。

形式はJSONを基本とする。座標や大きな結果データは、必要に応じてXYZ、CUBE等の別ファイルを参照する。

## 分子

```json
{
  "format_version": 2,
  "charge": 0,
  "spin": 1,
  "atoms": [
    { "id": 1, "element": "O", "x": 0.000000, "y": 0.000000, "z": 0.000000 },
    { "id": 2, "element": "H", "x": 0.758602, "y": 0.000000, "z": 0.504284 },
    { "id": 3, "element": "H", "x": -0.758602, "y": 0.000000, "z": 0.504284 }
  ],
  "bonds": [
    { "id": 1, "from": 1, "to": 2, "order": "single" },
    { "id": 2, "from": 1, "to": 3, "order": "single" }
  ]
}
```

`spin`はスピン多重度。`id`は原子・結合の安定IDで、`bonds`の`from`と`to`は原子IDを参照する。旧形式のインデックス参照とIDのない入力は読み込み時に互換処理する。`order`は結合の種類を表し、`"none"`（切断状態）、`"single"`（単結合）、`"double"`（二重結合）、`"triple"`（三重結合）、`"aromatic"`（芳香族結合）の5種類を文字列で指定する。切断状態の結合は原子間の結合として扱わず、再接続時に同じ結合IDを再利用する。

分子編集では、結合次数、結合長、結合角、二面角を編集できる。結合を境界とする連結領域の平行移動・回転にも対応し、環状構造を横切る二面角は編集不可として扱う。編集履歴はUndo/Redo用に管理する。

UIでは原子を順番に選択し、結合長は2原子、結合角は3原子、二面角は4原子を指定する。数値入力は結合長をÅ、角度を度で扱い、内部計算ではラジアンへ変換する。

2原子を選択して`B`を押すと結合次数を切り替える。`G`を有効にすると、結合長・結合角の編集対象を単一原子から結合で連結したフラグメントへ変更する。

## 計算設定

計算設定は初期段階ではDFTによる構造最適化だけを扱う。

```json
{
  "calculation": {
    "method": "DFT",
    "task": "optimize"
  }
}
```

`method`は現時点では`DFT`、`task`は`optimize`のみを許可する。汎関数、基底関数、溶媒、scan、freezeなどは今後の拡張で追加する。

## 入出力対応とrun

ライフサイクルは「定義 → 入力生成 → 実行中 → 成功/失敗/キャンセル → 結果登録」。実行ごとの記録は`runs/<run-id>/run.json`に置く。

```json
{
  "id": "2026-11-07T120000Z-water-opt",
  "task": "tasks/water-opt.json",
  "status": "succeeded",
  "started_at": "2026-11-07T12:00:00Z",
  "finished_at": "2026-11-07T12:00:08Z",
  "input": "input.inp",
  "output": "output.out",
  "log": "run.log"
}
```

構造化結果はJSON、軌道・密度等は`artifacts/`に置く。パスはプロジェクトルートからの相対パスとする。

## 互換性

`format_version`で形式を識別する。未知キーは読み捨てず、警告を表示して可能なら保持する。破壊的変更にはADRを追加する。
