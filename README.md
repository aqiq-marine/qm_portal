# qm_portal

wgpuiを用いた、独自フォーマットの量子化学計算管理ツールです。

通常のディレクトリを1つのプロジェクトとして扱い、JSONベースのファイルで分子情報、計算タスク、実行結果を管理します。GUIはこれらのファイルを編集・実行・可視化するための入口になります。

## 目的

- `charge`、`spin`、`atoms`、`bonds` からなる分子情報を再利用する
- 計算手法、汎関数、基底関数、溶媒、`scan`、`freeze` などの条件を明示する
- 入力ファイルと出力ファイルをタスク単位で対応づける
- 外部プログラムに依存する計算結果を再現可能な形で記録する
- 分子の結合次数、結合長、結合角、二面角、連結領域を編集する

## 分子編集

編集処理は `src/editor.rs` に分離し、幾何計算・分子グラフ探索・編集コマンド・Undo/Redoをテスト可能な形で管理します。既存の分子JSONはそのまま読み込め、原子・結合IDがない場合は読み込み時に補完されます。UIの選択操作と数値入力はこの編集基盤へ段階的に接続します。

現在のUIでは、原子を左クリックして選択し、`Shift` + クリックで複数選択できます。`B` は選択した結合の次数を単結合・二重結合・三重結合・芳香族結合の順で切り替えます。`L` は結合長、`A` は結合角、`D` は二面角の入力モードです。`G` を有効にすると結合長・結合角で連結フラグメント全体を移動します。選択後に数値を入力して `Enter` を押すと編集を適用し、角度は度、距離はÅで指定します。`Esc` で入力モードを解除します。

## プロジェクト構成

プロジェクトは特別なデータベースではなく通常のディレクトリです。Gitでそのまま差分管理・共有できます。

```text
my-project/
  project.toml
  molecules/
  tasks/
  inputs/
  outputs/
  runs/
```

フォーマットは [`docs/format.md`](docs/format.md)、運用は [`docs/workflow.md`](docs/workflow.md)、開発ルールは [`AGENTS.md`](AGENTS.md)、設計判断は [`docs/adr/`](docs/adr/) を参照してください。
